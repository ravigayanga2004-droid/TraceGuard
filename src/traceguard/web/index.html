How do I approve expected changes?

Review the differences first. To approve trusted changes, run this in a terminal using the same state directory as this dashboard:

traceguard approve --note "Reviewed expected changes"

Approval updates the baseline and keeps your audit history.

Getting started with monitoring

Choose a folder in Monitoring location above. TraceGuard watches that folder and its subfolders while this server runs, even if you close this browser tab. Stop the server with Ctrl+C to stop its monitor.

For monitoring without the dashboard, run traceguard watch. For a single check, run traceguard scan. Commands use the last folder selected for the same state directory. Stop any separately started watcher before switching folders.

Refresh reloads recorded data; it does not scan your files. Empty directories and directory timestamps are not tracked.
