How do I approve expected changes?

Review the differences first. To approve trusted changes, run this in a terminal using the same state directory as this dashboard:

traceguard approve --note "Reviewed expected changes"

Approval updates the baseline and keeps your audit history.

Getting started with monitoring

The dashboard displays recorded observations. To watch for new changes, run this in another terminal using the same state directory:

traceguard watch

For a single check, run traceguard scan

Refresh reloads recorded data; it does not scan your files. Empty directories and directory timestamps are not tracked.
